# 本地知识库系统 - 需求文档

## 1. 项目概述

### 1.1 项目背景
错题本学习系统需要一个本地知识库，用于存储和检索各类学习资料、文档、图片等，支持智能问答和知识检索。

### 1.2 项目目标
构建一个支持多数据源输入、多模态内容处理、智能检索的本地知识库系统。

---

## 2. 功能需求

### 2.1 数据输入源

| 数据类型 | 支持格式 | 说明 |
|----------|----------|------|
| **文本文档** | .txt, .md, .docx, .pdf, .pptx, .xlsx | 支持自动解析文本内容 |
| **图片** | .jpg, .png, .gif, .bmp, .webp | 支持OCR文字识别、图片描述 |
| **音频** | .mp3, .wav, .ogg | 支持语音转文字 |
| **视频** | .mp4, .avi, .mov | 支持提取字幕/音频转文字 |
| **网页** | URL, HTML | 支持网页内容抓取 |
| **代码** | .py, .java, .js, .ts 等 | 支持代码解析和索引 |
| **结构化数据** | .csv, .json, .xml | 支持表格数据处理 |

### 2.2 核心功能

#### 2.2.1 文档管理
- 文档上传（单个/批量）
- 文档预览
- 文档分类管理
- 文档标签管理
- 文档删除/归档
- 版本管理

#### 2.2.2 知识处理
- 文本提取（OCR、语音转文字）
- 文本分块（Chunking）
- 向量化（Embedding）
- 元数据提取（标题、作者、日期、关键词）
- 智能摘要生成
- 实体识别

#### 2.2.3 知识检索
- 语义搜索（向量相似度）
- 关键词搜索（全文检索）
- 混合搜索（语义+关键词）
- 过滤搜索（按分类、标签、时间）
- 相关文档推荐

#### 2.2.4 智能问答（RAG）
- 基于知识库的问答
- 引用来源标注
- 多轮对话
- 问题扩展/改写

#### 2.2.5 知识图谱（可选）
- 实体关系抽取
- 知识图谱可视化
- 关联知识发现

---

## 3. 非功能需求

### 3.1 性能需求
- 单文档处理时间 < 30秒
- 语义搜索响应时间 < 500ms
- 问答响应时间 < 5秒
- 支持并发用户数 ≥ 10

### 3.2 存储需求
- 单文档最大支持 50MB
- 知识库容量 ≥ 10GB
- 向量维度：768/1024/1536

### 3.3 兼容性需求
- 浏览器：Chrome, Firefox, Safari
- 移动端响应式设计
- API接口标准化（RESTful）

### 3.4 安全需求
- 用户认证（JWT）
- 数据加密存储
- 访问权限控制
- 操作日志记录

---

## 4. 用户角色

| 角色 | 权限 |
|------|------|
| 管理员 | 全部权限，用户管理 |
| 普通用户 | 上传、检索、问答 |
| 访客 | 只读检索 |

---

## 5. 系统集成

### 5.1 与错题本系统集成
- 统一用户认证
- 知识库与错题关联
- 学习资料智能推荐

### 5.2 与AI服务集成
- MiMo模型问答
- 支持扩展其他LLM
- Embedding模型可配置

---

## 6. 约束条件

- 部署在腾讯云服务器（3.6GB RAM）
- 本地部署，数据不出服务器
- 开源技术栈优先
- 成本可控
