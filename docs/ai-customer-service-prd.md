# 智能客服智能体 — 产品需求文档（PRD）

> **版本**: v1.0
> **日期**: 2026-09-28
> **状态**: 已确认

---

## 1. 产品概述

### 1.1 产品定位
通用智能客服智能体——基于大模型 + 知识库的多场景AI客服系统。支持多业务场景配置，AI优先自动回复，复杂问题转人工接管。

### 1.2 核心价值
| 价值 | 说明 |
|------|------|
| 降本增效 | AI自动处理80%常见问题，减少人工客服工作量 |
| 7×24服务 | 全天候自动响应，不受时间限制 |
| 多场景适配 | 通过知识库配置快速适配不同业务场景 |
| 人机协作 | AI无法解决时无缝转人工，用户无感知 |

### 1.3 目标用户
| 角色 | 说明 |
|------|------|
| 终端用户 | 通过Web对话窗口咨询问题的客户 |
| 人工客服 | 通过客服工作台处理转人工问题的客服人员 |
| 管理员 | 配置知识库、查看数据报表的运营管理人员 |

## 2. 产品范围

### 2.1 功能模块

| 模块 | 功能 | 优先级 |
|------|------|--------|
| **用户端对话** | 在线对话窗口、AI自动回复、转人工按钮、消息历史 | P0 |
| **AI对话引擎** | 意图识别、知识库检索、RAG回答、多轮对话、上下文理解 | P0 |
| **人工工作台** | 会话列表、实时消息、手动回复、会话转接、快捷回复 | P0 |
| **知识库管理** | 文档上传、FAQ管理、知识分类、知识审核、向量检索 | P0 |
| **工单系统** | 自动生成工单、工单分配、工单处理、工单关闭 | P1 |
| **数据报表** | 会话统计、响应时间、解决率、用户满意度、热门问题 | P1 |
| **系统管理** | 角色权限、场景配置、机器人设置、系统参数 | P2 |

### 2.2 用户场景

**场景1：常见问题自动回复**
> 用户："你们的营业时间是？"
> AI：基于知识库直接回答，无需人工介入

**场景2：复杂问题转人工**
> 用户："我的订单出了问题，需要投诉"
> AI：识别为复杂/敏感问题 → 自动转人工 → 客服接入

**场景3：多轮对话**
> 用户："我要退货" → "怎么操作？" → "退款多久到账？"
> AI：理解上下文，连续回答关联问题

**场景4：知识库未覆盖**
> 用户：提出知识库没有的问题
> AI：如实告知 + 引导转人工 + 自动生成工单

## 3. 功能需求

### 3.1 用户端对话窗口（P0）

| # | 需求 | 描述 |
|---|------|------|
| 1.1 | 对话界面 | 聊天气泡式界面，支持文本/图片/文件发送 |
| 1.2 | AI自动回复 | 发送消息后AI在2秒内自动回复 |
| 1.3 | 转人工按钮 | 用户可随时点击"转人工"切换到人工客服 |
| 1.4 | 消息历史 | 显示当前会话历史消息 |
| 1.5 | 会话列表 | 显示用户历史会话 |
| 1.6 | 等待提示 | AI回复时显示"正在输入..."动画 |
| 1.7 | 满意度评价 | 会话结束后弹出满意度评分（1-5星） |
| 1.8 | 常见问题 | 对话窗口上方展示FAQ快捷入口 |

### 3.2 AI对话引擎（P0）

| # | 需求 | 描述 |
|---|------|------|
| 2.1 | 意图识别 | 识别用户问题意图（咨询/投诉/操作/闲聊/转人工） |
| 2.2 | 知识库检索 | 语义+关键词混合搜索知识库 |
| 2.3 | RAG回答 | 基于检索结果生成回答，标注引用来源 |
| 2.4 | 多轮对话 | 维护对话上下文，支持追问和关联问题 |
| 2.5 | 转人工判定 | 识别投诉/敏感/无法解决的问题自动转人工 |
| 2.6 | 快捷回复 | 提供"相关问题"快捷按钮 |
| 2.7 | 回答兜底 | 知识库无答案时给出引导话术 |
| 2.8 | 会话摘要 | 自动生成会话摘要供人工客服参考 |

### 3.3 人工客服工作台（P0）

| # | 需求 | 描述 |
|---|------|------|
| 3.1 | 会话列表 | 显示待处理/处理中/已结束的会话 |
| 3.2 | 实时消息 | WebSocket推送新消息，实时对话 |
| 3.3 | 手动回复 | 客服输入文本/图片/文件回复 |
| 3.4 | 会话转接 | 将会话转给其他客服 |
| 3.5 | 快捷回复 | 预设常用回复模板 |
| 3.6 | 用户信息 | 显示用户画像和历史会话 |
| 3.7 | 会话标签 | 给会话打标签（咨询/投诉/售后等） |
| 3.8 | AI建议 | 显示AI生成的回复建议供客服参考 |

### 3.4 知识库管理（P0）

| # | 需求 | 描述 |
|---|------|------|
| 4.1 | 文档上传 | 支持txt/md/pdf/docx/xlsx等格式 |
| 4.2 | FAQ管理 | 添加/编辑/删除常见问题 |
| 4.3 | 知识分类 | 按业务场景分类管理知识 |
| 4.4 | 知识审核 | 知识入库前需审核通过 |
| 4.5 | 语义检索 | 向量检索，支持多格式 |
| 4.6 | 知识统计 | 知识覆盖度、使用频次统计 |

### 3.5 工单系统（P1）

| # | 需求 | 描述 |
|---|------|------|
| 5.1 | 自动创建 | 转人工时自动创建工单 |
| 5.2 | 工单分配 | 按规则分配给客服 |
| 5.3 | 工单处理 | 客服处理并记录处理结果 |
| 5.4 | 工单关闭 | 处理完成后关闭工单 |
| 5.5 | 工单查询 | 按状态/时间/类型查询 |

### 3.6 数据报表（P1）

| # | 需求 | 描述 |
|---|------|------|
| 6.1 | 会话统计 | 总会话数/独立用户数/平均会话时长 |
| 6.2 | 响应统计 | AI响应时间/人工响应时间 |
| 6.3 | 解决率 | AI独立解决率/人工解决率 |
| 6.4 | 满意度 | 用户满意度评分分布 |
| 6.5 | 热门问题 | 高频问题TOP10 |
| 6.6 | 趋势分析 | 按日/周/月统计趋势 |

## 4. 非功能需求

| 维度 | 要求 |
|------|------|
| **性能** | AI响应时间 < 3秒（P95），并发支持100用户 |
| **可用性** | 服务可用性 > 99%，支持故障自动恢复 |
| **安全性** | 数据加密传输，敏感信息脱敏，操作审计 |
| **可扩展** | 支持多场景配置，知识库热更新 |
| **易用性** | 用户3步内发起对话，客服5秒内接入 |

---

## 5. 业务规则

| 规则 | 描述 |
|------|------|
| 转人工触发 | ①用户主动点击 ②AI识别到投诉/敏感 ③AI连续2次无答案 ④用户情绪激动 |
| 会话超时 | 30分钟无消息自动关闭会话 |
| 工单优先级 | 投诉=高 / 售后=中 / 咨询=低 |
| 满意度评价 | 会话关闭后24小时内可评价 |
| 知识审核 | 新知识需审核后才能被AI使用 |
