🔒 安全与部署

安全设计

  • 密码 BCrypt 加密存储
  • JWT Token 有效期 7 天
  • Token Redis 存储，支持主动失效
  • 前端密码 Base64 编码传输
  • CORS 跨域白名单
  • HTTPS 强制 (TLS 1.2/1.3)
  • SQL 注入防护 (JPA 参数化)
  • 文件上传大小限制 (10MB)
