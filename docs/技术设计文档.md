## 1. 项目概述

### 1.1 项目背景

错题本是一款面向小学阶段学生（3-5年级）的智能学习辅助系统，旨在帮助学生系统化管理错题、巩固薄弱知识点、提升学习效率。系统基于护教版（五四学制）上海教材，提供错题收录、知识总结、拼音学习、数学专项、拓展实践、表现记录等完整功能。

### 1.2 核心功能模块

| 模块 | 功能说明 |
|------|---------|
| **错题管理** | 录入、编辑、搜索、删除错题，支持图片上传和分类标签 |
| **仪表盘** | 错题统计概览、学科分布、最近活动 |
| **知识总结** | 按学科和单元整理的知识点总结 |
| **拼音学习** | 声母韵母学习、拼读练习 |
| **数学专项** | 速算与巧算、数的整除、行程问题等专项训练 |
| **拓展实践** | 小实验、游戏、课外学习、运动规则 |
| **表现记录** | 考试/学习/日常表现、阶段汇总、奖惩记录 |
| **AI 技术** | AI 辅助功能模块 |
| **学习方法** | 学习方法和技巧分享 |
| **知识库** | 基于向量数据库的智能知识检索 |

### 1.3 目标用户

- 主要用户：小学3-5年级学生
- 管理用户：家长/教师

## 6. 后端设计

### 6.1 分层架构

```
Controller → Service → Repository → Database
    ↓           ↓
  DTO       Entity
```

- **Controller 层** — 接收 HTTP 请求，参数校验，返回响应
- **Service 层** — 业务逻辑处理
- **Repository 层** — 数据访问，基于 Spring Data JPA
- **DTO 层** — 数据传输对象，隔离内部实体和外部接口

### 6.2 认证流程

```
1. 客户端 POST /api/auth/login (用户名 + Base64密码)
2. 服务端验证密码 (BCrypt)
3. 生成 JWT Token (有效期7天)
4. Token 存入 Redis (支持主动失效)
5. 返回 Token 给客户端
6. 客户端后续请求携带 Authorization: Bearer <token>
7. JwtAuthInterceptor 拦截验证
```

### 6.3 拦截器配置

```java
// 需要认证的路径
/api/** → 需要 JWT Token

// 不需要认证的路径
/api/auth/register → 注册
/api/auth/login → 登录
/api/hello → 健康检查
/api/test/** → 测试接口
```

### 6.4 文件上传

- 最大单文件：10MB
- 最大请求：50MB
- 存储路径：`./uploads/`
- 支持格式：JPG、PNG、GIF
- 访问路径：`/uploads/{filename}`

server {
    listen 80;
    server_name ty66666.cloud www.ty66666.cloud;
    return 301 https://ty66666.cloud$request_uri;
}

# HTTPS 主配置
server {
    listen 443 ssl;
    server_name ty66666.cloud www.ty66666.cloud;

    # SSL 证书

    ssl_certificate_key /home/ubuntu/plugin/ssl/...key;

    location / { try_files $uri $uri/ /index.html; }
